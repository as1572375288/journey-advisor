# 舆情反查：小红书 / 携程 / 马蜂窝 / 大众点评的避雷与本地推荐

> 目的：官方信息（票价、开放时间）回答的是"能不能去"，
> UGC 舆情回答的是"去了会不会后悔"。两者必须都采，缺一不可。

## 0. 先查用户资料库，再查公开舆情（**排在最前面，别跳过**）

用户往往已经把**最硬的材料**存进 WorkBuddy 资料库了——本地人语音转写、手写清单、
朋友发的截图、扫描件。**这些是"私有源"，可信度高于任何公开 UGC**，
而且常常包含公开渠道根本搜不到的东西（赶集日期尾号、某家店要提前打电话、市场掉包套路）。

**漏查的代价（真实教训）**：一份本地人口述扫描件存在资料库里，
因为**文件名是「扫描文档20260922_191506」这种无语义标题**，
用「鲅鱼圈 / 本地人推荐 / 赶海」等关键词 `search-nodes` **全部 0 命中**，
导致整版攻略缺了本地人情报；最后靠**列目录**才翻出来。

**正确动作（用 `library` skill）**：
1. **关键词搜一遍**：`space_api.py space.searcher.search-nodes --query "<目的地>"`
2. **0 命中不等于没有 → 必须列目录**：`space_api.py space.workspace.list-node --space-id <spaceId>`
   （先 `space.workspace.list-user-spaces` 拿 spaceId）
   **扫描件 / 截图 / 语音转写的标题往往没有语义，只能靠列目录发现。**
3. 发现 drive 类节点 → `node-info` 看 `ext`；**PDF/扫描件用 `search/rag_search.py --node-id <id>` 读 OCR 文本**，
   不要因为"是扫描件就以为读不了"。
4. 命中后按下面 §1–§7 的口径处理，并在来源标注里写明
   `实查 · <日期> · 本地人口述（资料库 <文件名>）`。

**优先级**：本地人口述 / 私有资料 **>** 官方源 **>** 公开 UGC。

## 1. 为什么必须有这一步

| 只做官方核验 | 只听 UGC | 两者都做 |
|---|---|---|
| 票价对、时间对，但踩了宰客套路 | 故事好听，票价时刻全是编的 | 数字可查 + 坑位可避 |

**典型代价**（真实教训）：
- 景区第一排海鲜店溢价 2–3 倍，官方票价页完全看不出来
- 山顶观景台周一常闭，官网不写、导航不更新
- "温泉入户"民宿实为锅炉加热，预订平台照片看不出
- 某站到城区打车 40 分钟，而另一站只要 20 分钟——只看车次会选错站

## 2. 平台全景：按用途分工，不要只用一个

**核心原则：一个平台给不出真相。** 至少 **2 个平台结论一致**才写进正文；
平台之间打架时，以 **「官方源 + 时间最近」** 为准。

| 平台 | 主打用途 | 擅长给什么 | 检索词模板 |
|---|---|---|---|
| **小红书** | 避雷 + 新鲜度 | 避雷、出片机位、排队时长、本地小店、最新闭园/装修/涨价 | `{目的地} 避雷` / `避坑` / `本地人推荐` / `别去` / `{店名} 真实` |
| **大众点评** | **吃饭第一源** | 餐厅四项子分、人均、差评、套餐陷阱、本地 vs 游客构成 | `{目的地} 海鲜` / `老店` / `苍蝇馆子` → **必看 1–3 星** |
| **美团** | 吃饭 + 实际成交价 | 团购真实价、套餐内容明细、销量、闭店/歇业状态 | 同上；团购页看"规格"里的克重与品种 |
| **携程** | 行程/门票/交通 | 行程节奏、门票省钱技巧、中转交通、景区问答区、包车报价 | `{目的地} 怎么玩不踩雷` / `{景点} 保姆级攻略` |
| **携程笔记**（社区/笔记流） | **刚去过的人怎么说** | 带时间戳的实拍、真实吐槽、酒店与景点当下状态、避开网红滤镜 | 携程 App → 搜目的地 → 切「笔记」标签；或 `{景点} 笔记` |
| **马蜂窝** | 长线玩法 | 多日行程、季节优劣、小众点位、蜂蜂问答 | `{目的地} 自由行 攻略` / `{目的地} 值得去吗` |
| **去哪儿 / 飞猪** | 门票与退改 | 真实成交票价、退改规则、联票组合 | `{景点} 门票 退改` |
| **抖音 / 快手** | 眼见为实 | 视频看真实店面、排队、分量、后厨；本地团购券 | `{店名} 值不值` / `{目的地} 美食 探店` |
| **B 站** | 动线与时长 | 长 vlog 看实际步行距离、景点真实体量、耗时 | `{目的地} vlog` / `{目的地} 攻略` |
| **知乎** | 值不值 | 深度对比、"X 值不值得去"、理性分析 | `{目的地} 值得去吗` / `为什么` |
| **微博** | 实时突发 | 闭园、天气突变、事故、临时管制 | 搜实时：`{景点} 闭园` / `{目的地} 台风` |
| **高德 / 百度地图 POI** | 覆盖与复核 | POI 评分基数最大；**最新评价**能反映当前状态 | 地图内搜店名 → 看"最新"排序 |
| **本地贴吧 / 论坛 / 微信群** | 最硬核 | 本地人才知道的店、真实行情价 | `{地名}吧` + `吃饭` / `哪家好吃` |
| **景区公众号 / 文旅局号** | **实时状态唯一信源** | 闭园、开放时间变更、临时活动 | 官方号，不靠聚合站 |
| TripAdvisor / Google Maps | 境外 | 境外餐饮与景点 | 境外目的地才用 |

**境内一律优先国产平台**（见 SKILL.md 地图规则）。

### 2.1 携程笔记：为什么它比纯种草平台更可信

携程笔记的**结构性优势**：作者大多真的在携程下过单，笔记与订单、酒店、门票数据在同一个账号体系里跳转，
**刷单成本比纯内容平台高得多**。加上笔记天然带发布月份，时效好判断。所以它是「可信度 / 时效性」平衡最好的一档。

**用它的三种最佳场景**：

| 场景 | 怎么用 |
|---|---|
| **临期状态**（最重要） | 出发前 1–2 周搜 `{景点} 笔记` + 按最新排序，看有没有闭园 / 装修 / 涨价 / 排队的近期实拍——这是官方公告之外最灵的信号 |
| **酒店真实情况** | 搜 `{酒店名} 笔记`：朝向是不是真海景、楼下有没有烧烤摊噪音、距海边实际步行几分钟。**订房平台的照片看不出来的，笔记里有** |
| **景点该留多久** | 笔记里常写「几点到、几点走」，比攻略站的建议时长更贴近现实 |

**和大众点评/美团搭配**：吃饭用点评（看子分与差评），订房订票前用携程笔记做**最后一道核验**。

**注意**：携程笔记同样有达人置换与商家合作，**末尾带「合作/赞助」字样、图片全是精修摆拍的降权处理**；
优先看**普通人账号 + 随手拍 + 写了具体时间**的笔记。

**每个核心玩法至少两次定向检索**：`{玩法} 避坑`（如"赶海 避坑"）与 `{玩法} 本地推荐`。
**涉及吃饭的，餐饮专章（§7）是必走流程，不是可选项。**

## 7. 餐饮评价专章：点评/美团怎么读才不踩坑

餐厅是旅行里**最容易被刷分、也最容易踩雷**的一环。官方票价查得再准，一顿饭被宰就毁了半天心情。

### 7.1 别只看总分，看四项子分

大众点评把评分拆成 **口味 / 环境 / 服务 / 食材**（部分版本为三项）。
- 总分 ≥4.5 且**四项均衡**才算稳；
- 出现「环境 4.9 / 口味 3.8」= 网红装修店，别去；
- 出现「口味 4.7 / 服务 3.5」= 味道好但忙起来顾不上，老人同行要慎重（等餐久、吵）。

### 7.2 好评可刷，差评难删——倒着读

**直接切到 1–3 星，按时间倒序看最近 3 个月。** 重点抓这几类：

| 差评关键词 | 真实含义 |
|---|---|
| "分量小""和图片不符" | 分量虚标，带老人孩子不够吃 |
| "结账和菜单不一样""多算了" | **计价套路**，硬避雷 |
| "等了 40 分钟""上菜慢" | 高峰期别去，老人扛不住 |
| "点的活虾上桌是死的" | 后厨调包，海鲜店头号坑 |
| "团购券不能用""套餐里没有" | 套餐暗藏限制 |
| "本地人都不来" | 已经定性为游客店 |

好评里**最真实的是带具体细节的中评**（"蛏子挺肥但偏咸"），通篇"太好吃了绝绝子"的一律无视。

### 7.3 识别刷单：看评价的时间与人

- **时间分布**：好评集中在某三五天爆发 → 刷单；平稳持续几个月 → 真实。
- **评价人构成**：写"带爸妈来""每周来""下班顺路"的是本地/复购，**权重要高于**"来旅游打卡""导游带去的"。
- **图片风格**：全是精修+滤镜+摆拍 → 达人置换；随手拍、有菜单入镜 → 真实。
- **人均价格**：只看"近 90 天"，老评价里的价格已经过时（尤其海鲜时价）。

### 7.4 分辨「游客店」和「本地店」

| 特征 | 游客店（躲） | 本地店（去） |
|---|---|---|
| 位置 | 景区第一排、广场正对面 | 往里走两条街、居民区/市场旁 |
| 门口 | 有揽客、有巨型彩色菜单灯箱 | 无揽客，门脸朴素 |
| 菜单 | 图多、标"时价"、无克重 | 明码实价、写清斤两 |
| 点评内容 | 全是游客照、夸环境 | 有本地话、提"常来" |
| 高峰时段 | 饭点全是游客 | 饭点本地口音多 |
| 团购 | 套餐含糊、限制多 | 套餐与单点同品质 |

**一句话操作法**：海边/景区第一排的店一律跳过，往里走两条街，找**本地大爷大妈扎堆**的那家。

### 7.5 榜单怎么用

- **必吃榜**：有参考价值但商业化争议大，当作"候选池"，不当结论。
- **黑珍珠 / 米其林**：评审更严，但客单价高，带爸妈出行要算预算。
- **口味榜 / 热门榜（本地榜）**：比全国榜靠谱，因为它按城市本地口味排。
- **销量排序 ≠ 好吃**：销量高可能只是位置好、团购便宜。

### 7.6 地域口味差要打折看

评分是**当地人打的**。东北菜重口、量大，南方游客可能打低分；清淡菜系反过来。
**看评价时要判断打分人来自哪里**，跨地域看分数至少留 0.3 的误差带。

### 7.7 实战五步（写进手册前必走）

1. 搜 `{目的地} {品类}`（如"某海滨城市 海鲜"）→ **按评分排序**取前 10；
2. 再 **按评价数排序**取前 10；
3. **取交集**——既高分又高热度，才是真热门；
4. 交集里每家切到 **1–3 星差评** 扫一遍，出现"计价/调包/分量"类直接淘汰；
5. 剩下的交叉验证：小红书搜 `{店名} 真实`、抖音搜 `{店名}` 看视频实物，确认后写入。

**写进手册时必须带**：`参考 · 2026-09 · 人均与价格旺季上浮`，并注明**去哪个时段**（早市清晨 / 收摊前 / 工作日上午 / 避开饭点）。

## 3. 归类：五桶法

搜到的东西先分桶，再决定进不进正文。**不分桶直接贴 = 信息噪音。**

| 桶 | 内容 | 是否进正文 |
|---|---|---|
| A **硬避雷** | 宰客套路、虚假宣传、闭园时段、黑车、安全隐患 | ✅ 必进，写进对应玩法章节 |
| B **省钱技巧** | 提前一天订票省几元、某时段免费入园、自带什么 | ✅ 必进，写进预算或门票提示 |
| C **本地推荐** | 本地人扎堆的早市/小店/老字号、加工费 | ✅ 必进，单独成"本地人清单" |
| D **时令/安全** | 涨潮速度、赤潮期、海蜇、禁捕规定 | ✅ 必进，写进安全卡 |
| E **主观感受** | "落日封神""沙细像踩云" | ⚠️ 只在首屏用一句，不铺陈 |

**丢弃**：明显是商家软文（通篇夸同一家店、带团购链接）、无时间标注的旧文、无法核实的孤例。

## 4. 落地映射规则（关键）

舆情**不许堆在文末当附录**，必须打散映射到它该在的位置：

| 舆情类型 | 落到哪个模块 |
|---|---|
| 宰客套路 / 加工费 | 模块 5「在地体验」→ 海鲜怎么吃 |
| 门票省几元 / 免费时段 | 模块 3 对应每日卡 + 模块 6 预算 |
| 站的选择 / 黑车 | 模块 4「交通衔接」 |
| 涨潮 / 海蜇 / 禁捕 | 模块 5 安全卡 |
| 早市 / 老店 / 老字号 | 新增「本地人清单」小节（放在模块 5 末尾） |
| 民宿锅炉加热 / 海景房朝向 | 模块 3 住宿提示 + 模块 7 复查清单 |

**并同步改行程本身**：舆情若暴露原方案的结构性问题（如选错高铁站、某景点周一闭园恰巧排在周一），
必须改 Day 安排，而不是只加一句提示。

## 5. 三色标注同样适用

舆情也是事实，照样标：

| 情形 | 标注 |
|---|---|
| 多人反复提到、有具体门店/价格 | `实查 · 2026-09-22 · 多篇 UGC 一致` |
| 单篇提到、可能过时 | `参考 · 2026-09 · 出发前复核` |
| 无法确认的孤例 | **不写**，或进复查清单 |

**价格类舆情尤其要标**：UGC 里的"人均 60""加工费 20"是当时当地值，必须写 `参考` 并提示波动。

## 7. 定稿复检（第二轮 · 必做）

初轮舆情服务于**草案**，复检服务于**定稿**——两者搜的东西不一样。

| | 初轮（草案阶段） | 复检（定稿后） |
|---|---|---|
| 检索对象 | 目的地整体（"XX 避雷"） | **最终点位清单逐个点** |
| 目的 | 决定行程结构 | 决定执行细节与买票方式 |
| 必查 | 有没有坑、值不值得去 | 下面四类"到场才发现就晚了"的信息 |

**复检必查四类（逐条销账）**：

1. **票务优待政策**：老人/儿童**半价或免费的年龄门槛**（60–69 / 70+ 是常见分界）、免票证件要求。
   ⚠️ **线上渠道卖的成人票通常不享优待** → 结论必须写成"**年轻人线上买，老人现场凭证件买**"，
   不能笼统写"门票线上订更便宜"。
2. **设施有无**：淋浴/冲洗点、厕所（**是否收费**）、停车（是否收费、能不能停外面）、母婴设施。
   带老人小孩的行程，**"有没有地方冲洗换衣"是刚需级信息**，漏了等于当天要临时抓瞎。
3. **口碑是否两极**：尤其"住宿+餐饮+温泉"打包型度假区（洗浴民宿聚集区），
   同一片区不同店体验天差地别 → 结论要写成"**只泡不住 + 进店先看池水、问清计价方式**"这种可执行动作。
4. **新避坑**：停车乱收费、假门票/内部通道兜售、沙滩杂物（烟头/烟花棍）、厕所收零钱、蚊虫。

**输出要求**：复检结论**必须落到具体日的每日卡**（不能只更新文末的"待复查清单"），
并在「事实标注统计」里单列一行「舆情复检 · 日期 · 覆盖哪些点位」——**让读者知道哪些数是最新的**。
