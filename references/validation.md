# 事实核验清单

生成攻略前必须实查的时效信息。每条按状态标注**并写明数据时间**。查不到写「待复查」，禁止凭记忆填数。

## 必查清单

### 1. 大交通
- 高铁：车次、发到站时刻、历时、二等座票价 → 12306（https://www.12306.cn/）、携程火车票
- 航班：班次、时刻、含税价 → 航司官网、携程/飞猪
- 自驾：里程、时长、过路费、充电点（电车）
- 标注旺季/节假日浮动，给出「现在订」建议

### 2. 当地交通
- 车站/机场到住宿：打车费用区间、时长
- 住宿到各景点：打车费用、时长
- 是否需预约接站

### 3. 天气
- 覆盖全部旅行日期的逐日预报 → 中国天气网（https://www.weather.com.cn/）、墨迹天气
- 温差、降水概率、风力 → 转成穿搭/备选建议
- 超过 7 天的预报只能标「参考」，临近再复查

### 4. 潮汐（海滨/赶海目的地）
- 逐日退潮时间 → 爱潮汐表（https://www.aichaoxibiao.com/）
- 潮差级别：大潮 / 中潮 / 小潮
- 赶海窗口：退潮前后 2 小时
- 出发前 48h 复查；多源不一致时**并列出**，不擅自取一个

### 5. 景点
- 开放时间（含停止入园时间）、门票价格
- 老人/儿童/学生优惠（常见 60–64 半价、65+ 免票，**须带身份证**，实际以景区公示为准）
- 是否需要预约、旺季排队时长
- 信源：官方公众号、携程/美团页面

### 6. 预订与价格
- 热门景点门票、热门餐厅：预订窗口（提前 N 天 / 卖完风险）
- 海鲜/餐饮参考区间，标注「旺季上浮」

### 7. 一切"看起来像事实"的数字（极易漏，逐个查）
上面 1–6 是主线，**真正容易翻车的是这些边角数字**，它们同样属于"事实数据"：

- 景点间**里程与车程时长**（用地图实查，不估）
- 打车/网约车**费用区间**
- **人均消费**（别按"感觉"给，取点评/美团区间或明确写估算）
- **排队时长**、**停车费**、**观光车/缆车费**
- 餐厅**营业时段**与是否歇业日
- 潮汐**潮差数值**、天气**温差数值**

## 所有数字都要有出处（硬规则）

生成后把正文**逐字扫一遍数字**，对每个数问一句：**这个数从哪来的？**

| 答得出来吗 | 处置 |
|---|---|
| 能，本次实查 | 标 `实查 · 日期`，保留 |
| 能，但有浮动 | 标 `参考 · 时间 · 浮动说明`，保留 |
| 答不出来 | **删掉**，或改 `待复查` 并写进复查清单 |

**三种写法对照**：

- ✅ `打车约 30 min / 20.1 km（实查 · 2026-09-22 高德）`
- ✅ `人均 ¥80–120（参考 · 2026-09 点评区间，旺季上浮）`
- ❌ `打车大概半小时`（没来源、没标注 —— 读者会当事实，出事就是你的责任）

**宁可留空，不可填假。** 一个待复查项最多让用户多查一次；一个编造数字会让整份攻略失去可信度。

## 标注规范

| 标注 | 含义 | 写法示例 |
|---|---|---|
| 实查 | 本次经搜索/页面确认为当前有效，**来源见末尾来源表** | `实查 · 2026-09-22` |
| 平台核 | 在**具体平台页面**上亲眼看到 —— 可信度最高 | `平台核 · 大众点评 · 09-28` |
| 本地口述 | 出自本地人语音；**已逐条尝试核价**，仍标本档 = 公开平台**核不到出处** | `本地口述 · 价格未核到` |
| 网络攻略 · 未核实 | 自媒体 / 攻略站转述，未回源 | `网络攻略 · 未核实` |
| 参考 | 有来源但会浮动（价格、旺季） | `参考 · 2026-09 · 旺季上浮` |
| 待复查 | 查不到或两源对不上 | `待复查 · 出发前 48h` |

## 来源可核对（v1.2.9 新增 · 返工教训）

三色标注只解决"可信度"，**不解决"能不能自己核"**。带老人小孩的长途攻略，用户会想自己复查——
所以每个数据点还要**标得出具体出处**，落到「平台名 + 日期」或「哪份口述 / 哪份公告」。

**① 不许张冠李戴** —— 数据真实来源是什么就标什么。
**平台评分 / 条数 / 人均绝不能标成 `本地口述`**（本地人不会说"1463 条评价"）。
> 返工案例：鲅鱼圈手册把**大众点评 4.8 分 / ¥92 人**写成 `本地口述 · 4.7 分 / 1463 条 / ¥103 人`，
> **三项全不对**；同一家店携程 ¥94、点评 ¥92、口述又一套数字。

**② 精确数字必须能指回页面** —— "4.7 分 / 1463 条 / ¥103 人""12 只 ¥35–50""溢价 20–40%"这类精确值**最像编造**。
要么指得回具体页面，要么**删掉 / 降级为待复查**。
> 返工案例：观景台票价写"¥30–40（30 与 40 并存）"，实际只有 **¥30（携程攻略，含儿童免票细则）与 ¥20（另一游记）**
> —— **"40"根本没有出处**；望儿山写"线上比现场省 ¥8–10"，实际平台 ¥35 / 门市约 ¥40，**只差 ¥5**。

**③ 查不到就明说，并交代怎么核** —— 不是删掉了事：写成 `网络攻略 · 未核实` / `待复查`，
**并在末尾告诉用户"去哪查、搜什么词"**。

**交付物末尾宜附「来源与自查指引」**，三块：
① **来源表**（类别 → 具体平台/文件 → 日期）；② **各级标注怎么读**；
③ **照抄关键词的自查清单**（"12306 输 `K4118`"、"中国天气网搜 `鲅鱼圈 101070806`"、"大众点评搜店名，倒着读差评"）。

## 本地口述必须逐条核价（v1.3.0 新增 · 返工教训）

**`本地口述` 不是免责标签。** 写"未在平台复核"只是**声明**，不是**交代**——
用户拿到手还是要自己核。正确做法：**把口述里的每个数字捞出来，逐条上平台搜一遍**，三分类落地。

**工作流（口述情报入库后必跑）**：

1. **捞**——全文搜 `本地口述` / `本地人` / `口述`，把带**数字**的条目列成清单（价格、时长、人均、里程、时间）。
2. **核**——逐条按「信源优先级」搜一遍（官方 > 平台 > 攻略）：
   - **对的** → **升级标注**为 `平台核 · 平台名 · 日期`，别继续挂 `本地口述`。
   - **错的** → **当场改数**，并在正文/清单说明纠正了什么（不要静默改掉）。
   - **核不到的** → 保留 `本地口述`，但**加一句"价格未在平台核到"**，并给一个可比参照（如"同品类约 X 元"）。
3. **销账**——把能远程核的写进待复查清单并当场销掉，剩"必须到场/电话"的写清打哪个电话问哪句。

**返工案例（鲅鱼圈 2026-09-28 全量核口述价，11 处）**：

| 口述项 | 核后结论 |
|---|---|
| 温泉"胡同 20 元/1.5 小时" | ✅ **官方媒体印证**（营口新闻传媒中心：双台镇大众浴池两小时 20 元）→ 升级，并**修正为"2 小时"** |
| 打车"城区→双台镇 30 元" | ✅ 对得上；并**补出官方运价**（区政府公示：起步 6 元/2km、**国庆 10/1–3 每车次 +3 元**）—— 口述里没有的新信息 |
| 葡萄"10 元 3 斤" | ✅ 同期产地批发 2.5 元/斤（惠农网），零售合理 |
| 杨家吊炉饼"¥8/份" | ✅ 携程攻略原文一致 |
| 韩记"鲅鱼饺子 12 只 ¥35–50" | ✅ 攻略页有出处 → **撤掉"待复查"** |
| 四道沟"人均 ¥60" | ⚠️ 应为 **¥60–80**（多源）→ **改数** |
| **虞昇火锅粉"公开平台查不到"** | ❌ **真错**——Trip.com 有（3.5 分 / 4 条点评）→ **纠正标注**（原文误判"查不到"） |
| 脆火烧"2 元/个" | ➖ 公开平台**核不到** → 保留口述，注明"价格未核到"+ 给同品类参照 |

**关键提醒**：**"我查不到"本身可能就是错的** —— 换平台、换关键词（试 Trip.com / 城市吧 / 360 地图 / 马蜂窝）再试一次，
别一家搜不到就断言"平台没有"。虞昇这条就是漏检的反例。

## 信源优先级

1. **官方**：12306、航司、景区官方、气象局、官网潮汐表
2. **平台**：携程 / 美团 / 高德页面 —— 标「参考」
3. **社区**：小红书 / 马蜂窝 —— 仅作经验参考，不作为价格/时间依据

## 禁止

- 禁止凭模型记忆写具体票价、时刻、潮汐时间、开放时间
- 禁止编造预订信息（酒店名、航班号）
- 禁止把攻略经验当成事实
- 禁止把「待复查」写成看起来确定的数值
- **禁止张冠李戴**：平台数据标成口述、口述包装成平台数据，都是错标
- **禁止出现指不回出处的精确值**（带小数 / 带"条数" / 带"几分"的数字）
- **禁止把 `本地口述` 当免责标签、用一句"未复核"了事**——必须先逐条上平台核价，能对上的升级标注、核不到的明说

## 反编造自检（生成后执行）

四道扫，缺一不可：

1. **数字扫** —— 正文所有数字逐个问「从哪来？」答不出来 → 补查或改 `待复查`。
2. **来源扫** —— 所有 `实查` / `平台核` / `本地口述` 标注逐个问「**标对了吗？**」
   尤其查：平台数据有没有被标成口述、口述有没有被包装成平台数据。
3. **精确值抽扫** —— 带小数、带"条数"、带"几分"的精确值，抽查能否指回页面。
4. **口述扫** —— 所有 `本地口述` 的数字**逐条上平台搜一遍**（换平台、换关键词），
   能对上的**升级为 `平台核`**；核不到的注明"未核到"。**别把"未复核"当条目标签就交差。**

宁可留空，不可填假。一个待复查项最多让用户多查一次；一个编造数字会让整份攻略失去可信度。
